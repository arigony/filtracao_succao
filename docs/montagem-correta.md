# Montagem correta

## Linha principal

Bancada aberta → suporte universal → garra → kitassato → adaptador de borracha → Büchner → papel-filtro.

## Linha de vácuo

Braço lateral do kitassato → mangueira espessa → braço lateral da armadilha → conexão superior da armadilha → mangueira espessa com derivação de respiro → aspirador de água.

A armadilha é representada como um frasco tipo Erlenmeyer com braço lateral, coerente com a Figura 1.74 da referência. O respiro controlado por pinça é uma derivação no circuito entre a armadilha e o aspirador. Durante a sucção ele permanece fechado. Para lavar a torta ou encerrar, o respiro é aberto primeiro, igualando a pressão à atmosfera.

## Papel e transferência

O papel cobre toda a placa perfurada, com concavidade para baixo. Uma pequena quantidade de solvente frio compatível é adicionada sob sucção para assentar a folha. A suspensão só é transferida após observar escoamento e aderência uniforme.
